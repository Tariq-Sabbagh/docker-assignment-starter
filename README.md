# Docker Assignment Starter

This is the starter repository for a beginner Docker assignment.
The application code is ready. Your job is to learn Docker.

1. Fork this repository on GitHub.
2. Clone **your own fork**:

   ```bash
   git clone <YOUR-FORK-URL>
   cd docker-assignment-starter
   git switch -c docker-assignment
   ```

3. Follow the separate **Docker Assignment PDF** from your mentor.
4. Write your notes in `REPORT.md` and save useful screenshots in `screenshots/`.
5. Commit your work as you finish each mission.

Some files are intentionally broken. Inspect the containers and read their
logs before changing files. The application code does not need changes.

Stop the previous exercise before reusing its host port.

Never commit passwords, Docker Hub tokens, API keys, private keys, or `.env`
files. The credentials supplied for the networking exercise are public,
lab-only examples. Do not use them for real systems.
